# SQL Database Management Project

## 📌 Project Overview

This project is a SQL database project created and executed using
**MySQL Workbench**.

The project demonstrates how to create tables, insert data, update
records, delete records, retrieve information, and analyse data using
SQL queries.

## 🗂️ Database Tables

The project contains four main tables:

1.  **Customers** -- stores customer information.
2.  **Orders** -- stores customer order information.
3.  **Products** -- stores product, price, and stock information.
4.  **OrderDetails** -- stores product quantity and subtotal for orders.

## 🛠️ SQL Concepts Used

The following SQL concepts and commands are demonstrated:

-   `CREATE TABLE`
-   `INSERT INTO`
-   `SELECT`
-   `UPDATE`
-   `DELETE`
-   `WHERE`
-   `BETWEEN`
-   `ORDER BY`
-   `GROUP BY`
-   Subqueries
-   `SUM()`
-   `COUNT()`
-   `MAX()`
-   `MIN()`
-   `AVG()`

## 📋 Table Details

### Customers

Stores details such as: - Customer ID - Name - Email - Address

### Orders

Stores: - Order ID - Customer ID - Order Date - Total Amount

### Products

Stores: - Product ID - Product Name - Price - Stock

### OrderDetails

Stores: - Order Detail ID - Order ID - Product ID - Quantity - Subtotal

## 🔍 Operations Demonstrated

### Data Insertion

Records are added to the tables using `INSERT INTO`.

### Data Retrieval

`SELECT` is used to display records and retrieve required information.

### Data Updating

`UPDATE` is used to modify existing customer or product/order
information.

### Data Deletion

`DELETE` is used to remove records according to specified conditions.

### Filtering

`WHERE` and `BETWEEN` are used to filter records based on conditions or
ranges.

### Sorting

`ORDER BY` is used to arrange results in ascending or descending order.

### Grouping

`GROUP BY` is used to group records and calculate totals for each
product.

### Aggregate Functions

Functions such as `SUM`, `COUNT`, `MAX`, `MIN`, and `AVG` are used for
data analysis.

### Subquery

A subquery is used to work with the maximum and minimum product prices.

## 🎯 Project Objective

The main objective of this project is to understand the practical use of
SQL for:

-   Creating and managing databases
-   Storing structured data
-   Retrieving required information
-   Updating and deleting records
-   Performing basic data analysis

## 💻 Software Used

-   **MySQL Workbench**
-   **MySQL**

## 👨‍💻 Conclusion

This project provides practical experience with SQL database operations
